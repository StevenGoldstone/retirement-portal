Starting Balances

Enter each balance at the beginning of tracking and the date tracking began. These values normally only need to be entered once.

Record Payments

Enter the payment amount for each account. Leave an account blank if no payment was made. The portal will subtract each payment from the current balance and update all calculations automatically.

Portal sign-in

The first account must be created in Firebase Authentication. The included setup guide shows the exact clicks.
